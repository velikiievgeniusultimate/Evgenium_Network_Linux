Как включить на iPhone

  1. Установите бесплатное приложение WireGuard из App Store. Разработчик — WireGuard Development Team.
  2. Введите токен выше и скачайте профиль. Safari сохранит его в «Файлы» → «Загрузки».
  3. Откройте WireGuard, нажмите «+» → «Создать из файла или архива» и выберите скачанный файл.
  4. Разрешите добавление VPN-конфигурации и включите переключатель профиля.

Если названия пунктов отличаются, выберите импорт туннеля из файла. Удалив файл из «Загрузок» после импорта, вы сохраните ключ только в приложении.

Другие устройства и ограничения

Профиль можно импортировать в официальный WireGuard для macOS, Windows, Android и Linux. Для нового устройства создайте свой профиль: одновременное использование одного файла на нескольких устройствах нарушает соединение.

Сайт выдаёт профиль; для VPN нужен работающий UDP-канал. При блокировке WireGuard оператором профиль не сможет подключиться. Это первая версия подключения для iPhone, без автоматического выбора туннелей.

Внешний трафик идёт через российский сервер в Эстонию. Маршрут IPv6 включён в профиль, но выход IPv6 пока недоступен: такой трафик блокируется вместо прямого выхода к оператору. Доступ к локальной сети зависит от системных маршрутов WireGuard.
