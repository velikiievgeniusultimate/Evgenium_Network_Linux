# Evgenium Android — лабораторная версия 0.1.2-alpha

Нативное Android-приложение на Java с strongSwan. Интерфейс отправляет команды
сервису Engine; IKE/IPsec работает в CharonVpnService независимо от экрана.
Это отдельный Android-клиент, Linux `vpn update` его не устанавливает.

## Возможности

- Android 8.0+ (API 26), target API 36; ARM64, ARMv7 и x86_64 в одном APK.
- Токен существующей панели, отдельный RSA-3072 ключ и сертификат устройства.
  Приватный ключ остаётся в AndroidKeyStore. Токен хранится зашифрованным AES-GCM,
  ключ шифрования также в AndroidKeyStore; резервное копирование отключено.
- Имя устройства изменяется через ту же серверную панель/API.
- Четыре маршрута: HSVDS → Эстония, прямой UDP, TLS и EvgeniumTunnel в Эстонию.
  Обе TCP-обёртки используют TLS 1.3, взаимную проверку сертификатов и IKE внутри.
- Первый автоматический запуск измеряет маршруты. Результаты отдельно для Wi-Fi
  и мобильной сети, пока без разделения по конкретному роутеру/оператору.
- Повторное подключение начинает с лидера. Ошибки учитываются до трёх;
  дальнейшее восстановление переходит к следующему маршруту. «Проверить маршруты»
  составляет рейтинг заново и сбрасывает счётчики.
- Проверка скорости: 4 МиБ в каждом направлении на маршрут; также Discord API,
  задержка и внешний IP. Передача тела измеряется отдельно от DNS/TLS подключения.
  Это выбор маршрута, а не измерение потолка канала. Отказ Discord API не исключает
  маршрут; при отказе скоростного сервиса работающий выход сохраняется как резерв.
- Смена физической сети, в том числе новое подключение того же типа, не расходует
  счётчик проигрышей. Незаконченный рейтинг не заменяет предыдущий; запись атомарна.
- После первого сбоя повторная проверка выполняется через 3 секунды; на исправном
  соединении сохраняется интервал 15 секунд.
- Проверка выхода имеет общий таймаут и второй адрес Cloudflare. Это два адреса
  одного оператора, а не независимые службы проверки.
- Зависшая запись во внешний TLS-сокет прерывается через 10–11 секунд независимо
  от входящего трафика. Один таймер обслуживает соединение, без таймера на пакет.
- Снимки очереди, потерь, времени записи и переподключений включаются в локальные
  диагностические записи, в том числе при успешной проверке связи каждые 15 секунд.
  Счётчики относятся к экземпляру транспорта (`started_at`), сравнивать их через
  переподключение клиента нельзя. UDP-потери ядра Android здесь не измеряются.
- Ограниченные локальные журналы: 1 МиБ + предыдущий файл. Автоматической отправки
  отчётов нет. Токены и содержимое пользовательских пакетов в журнал не пишутся.

## Подключение

Установите лабораторный APK, введите токен, подтвердите системный запрос VPN.
Нажмите «Подключить». Разрешение уведомлений позволяет видеть состояние в шторке.
В «Системная защита VPN» включите постоянный VPN и блокировку соединений без VPN,
если защита должна сохраняться при остановке приложения системой.

При обычном переключении профилей strongSwan держит блокирующий TUN.
Полная защита при падении процесса, перезапуске ОС и отзыве разрешения пока
не прошла всю матрицу испытаний. Не считать alpha готовой заменой основному VPN.

## Сборка

Linux, Java 21, Python 3, Git, curl, make, Perl, C/C++ toolchain.
Установите Android command-line tools, задайте ANDROID_HOME и установите SDK:

```bash
sdkmanager 'platforms;android-36' 'build-tools;35.0.0' 'build-tools;36.0.0' 'ndk;27.3.13750724'
sdkmanager --licenses
./android/build.sh
```

Скрипт скачивает закреплённые strongSwan/OpenSSL, проверяет ревизии и SHA-256
архива с генерируемыми файлами, накладывает overlay и запускает сборку и тесты.
Gradle Wrapper скачивает Gradle 8.13. Для лицензий SDK требуется согласие владельца.
Все три ABI собираются по умолчанию. EVG_ANDROID_ABIS может сузить список;
EVG_ANDROID_BUILD задаёт каталог сборки (по умолчанию android/.build).

APK: `.build/strongswan/src/frontends/android/app/build/outputs/apk/debug/app-debug.apk`.
Это **debug-подпись**, не постоянная подпись выпуска. Не распространять как stable.
Для публичного выпуска нужны постоянный signing key, проверка лицензий всех
бинарных зависимостей, полный архив соответствующих исходников и тесты ниже.

## Архитектура и безопасность

`prepare.py` применяет небольшой повторяемый overlay к закреплённому upstream.
Остальной JNI/IKE код остаётся upstream. Нужен обычный Android VpnService, root
и Google Play Services не требуются. TLS для API 26–28 предоставляет Conscrypt;
API 29+ использует системный провайдер. Проверка CA/имени сервера не отключается.
Сокеты транспорта защищены от попадания в свой VPN и привязаны к физической сети
с INTERNET/NOT_RESTRICTED; IMS-сеть не выбирается как интернет.

В debug-сборке есть ADB-команды `lab`: enroll, connect, rank, stop, baseline, fault, measure, packet-lab, mobile-check.
Токен enroll читается один раз из приватного файла и удаляется; в Intent его нет.
`lab-forward` только для изолированной проверки старого Android через ADB reverse:
TCP идёт на loopback 34571/34578, а сертификат всё равно проверяется как эстонский.
`fault` временно обрывает только локальный EvgeniumTunnel, затем записывает
ограниченную серию проверок выхода. Эти команды игнорируются без FLAG_DEBUGGABLE.

`packet-lab` — отдельный синтетический стенд: mTLS stream echo и UDP carrier echo
с группировкой 1/10/32, подача пачками по 10 при 5/20/50 Мбит/с. Требуется активный
TLS/EvgeniumTunnel и специально запущенные аутентифицированные тестовые серверы.
Он не измеряет полный IPsec/VPN-путь. Тестовые сокеты защищены от своего VPN;
маршруты остального трафика не меняются. Отчёт: `packet-lab.json` в приватных файлах.
`mobile-check` делает ограниченные HTTPS-запросы к ВК, Яндексу, Google и Wikipedia
именно через доступную мобильную сеть; результат включает способ DNS-разрешения.
В debug-стенде есть явно помеченный резерв из IP, разрешённых 22.10.2026, если
мобильный DNS не отвечает за 3 секунды. Проверка TLS-имени остаётся обязательной.
Эти IP не используются рабочим VPN. Автоматически проверки не запускаются.

Группировка рабочего Android-трафика по-прежнему отключена (один пакет на flush):
короткие прогоны не доказали устойчивого преимущества нового значения на всех путях.
Wire format остаётся EvgeniumTunnel v1, отдельного протокола PC/M нет.

## До публичного выпуска

- Расширение испытаний LTE и смены сети на других операторах/телефонах.
- Doze, ночь простоя, экономия батареи производителей, перезагрузка, отзыв VPN,
  падение процесса, отсутствие сети, captive portal, Android always-on/lockdown.
- Реальный ARMv7, устройства с 16-КиБ страницами, дополнительные версии Android.
- Несколько независимых служб проверки выхода (сейчас проверка зависит от одного
  HTTPS-сервиса), DNS fallback, обновление сертификата до истечения,
  защита от повторных параллельных команд и тесты всей машины состояний.
- Исключения приложений, отчёт по согласию пользователя, устойчивые релизные подписи
  и механизм обновления. Эти функции Linux ещё не перенесены.
