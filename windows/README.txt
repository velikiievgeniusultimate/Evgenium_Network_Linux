Evgenium Network для Windows 10/11 x64 — первая тестовая версия 0.1.0

НАЧАЛО
1. Распакуйте ZIP целиком в обычную папку. Запустите Evgenium.exe.
2. Вставьте токен EVN1 и имя устройства, нажмите «Подтвердить».
3. Нажмите «ВКЛЮЧИТЬ» и подтвердите UAC своей учётной записью Windows.
Официальный WireGuard устанавливается автоматически, только после проверки
подписи издателя WireGuard LLC. Во время установки нужен обычный интернет.
Права администратора нужны для установки WireGuard и управления туннелем.
Другие VPN приложение не отключает. Для проверки используйте один VPN.

Токен общий для человека. На этом устройстве создаётся отдельный закрытый ключ.
Токен и ключ защищены DPAPI текущего пользователя Windows. Постоянная
конфигурация службы защищена ACL (пользователь, SYSTEM, администраторы).
Не передавайте каталог %LOCALAPPDATA%\EvgeniumNetwork другим людям.

ПОДКЛЮЧЕНИЕ
Компьютер -> HSVDS -> защищённый межсерверный канал -> Эстония.
Успех показывается только после проверки выхода 38.180.164.67 через адрес VPN
и обращения к Discord по HTTPS (с проверкой DNS).
При обрыве работающая служба WireGuard блокирует обычный интернет. Для возврата
к обычному интернету нажмите «Отключить». Закрытие окна НЕ отключает VPN.
Кнопка «Включить» повторно проверяет работающий туннель. Драйвер WireGuard
сам переживает смену Wi-Fi/кабеля. Этот первый клиент поддерживает один маршрут
WireGuard через HSVDS; UDP может блокироваться оператором. Система рейтинга
маршрутов Linux/Android и исключения приложений сюда пока не перенесены.

УСТАНОВИТЬ В МЕНЮ «ПУСК» (не обязательно)
EvgeniumCLI.exe install
После этого запускайте Evgenium Network через меню «Пуск».

ОБНОВЛЕНИЯ
Кнопка «Обновить» или EvgeniumCLI.exe update получает манифест и ZIP с GitHub.
Проверяются точный адрес репозитория/релиза, SHA256, структура ZIP, версия и
самопроверка нового EXE. Токен, ключ и имя сохраняются. VPN не отключается.
При ошибке проверки старая версия остаётся. После успешного обновления закройте
старое окно и запустите приложение через меню «Пуск».

CLI
EvgeniumCLI.exe token     ввод токена без отображения, затем имя устройства
EvgeniumCLI.exe on        включение и проверка выхода
EvgeniumCLI.exe off       отключение собственного туннеля
EvgeniumCLI.exe status    состояние с проверкой внешнего IP и DNS
EvgeniumCLI.exe update    обновление через GitHub
EvgeniumCLI.exe install   установка в меню «Пуск»
EvgeniumCLI.exe selftest  проверка клиентских правил без подключения

ОГРАНИЧЕНИЯ ПЕРВОГО ВЫПУСКА
Собственные EXE пока без сертификата подписи издателя. Не отключайте SmartScreen
или антивирус. Проверяйте источник ZIP и SHA256; если политика организации
запрещает неизвестные приложения, обратитесь к её администратору.
Собственный GUI/CLI не меняет политику выполнения PowerShell.
WireGuard и его драйвер имеют официальные подписи своего издателя.
Настоящего прогона на физическом Windows-ПК при подготовке ещё не было:
статус тестового выпуска нужно учитывать. Нужна Windows с curl.exe (актуальные
Windows 10/11). Работа на ARM64, Windows 7/8 и Wine не заявляется.

УДАЛЕНИЕ
Сначала EvgeniumCLI.exe off. Затем удалите приложение из меню «Пуск» и каталог
%LOCALAPPDATA%\EvgeniumNetwork. Устройство также отзовите в панели владельца.
WireGuard при необходимости удаляется обычными средствами Windows.
