Evgenium — настоящий провайдер Windows 11 Widgets Board (Win+W)

Состояние: исходник прототипа; не включён в основной установщик.
Старое плавающее окно удалено из основного приложения.

Провайдер использует официальный IWidgetProvider. Карточка показывает состояние,
переключает VPN через то же ядро/повышение UAC и открывает главное окно.
Нет собственного окна поверх рабочего стола, удалённого веб-сервера, токенов
или ключей в карточке. Устаревшее состояние не показывается как подключение.
Оформление Adaptive Card зависит от темы системной панели Windows. Точная копия
плавающего KDE-виджета через этот API невозможна. На Windows 10 панели нет.

Для обычной установки пользователям нужен подписанный MSIX или публикация через
Microsoft Store. Неподписанный MSIX нельзя объявить готовым к распространению.
Не включать Developer Mode и не добавлять свой корневой сертификат на компьютеры
клиентов ради обхода этого требования. Сертификата для подписи сейчас нет.

До выпуска: сборка/проверка COM и MSIX, подписать пакет, проверить в настоящей
панели Win+W на Windows 11 (не только на Windows Server в CI), проверить
закрепление/удаление, UAC, восстановление провайдера, светлую/тёмную тему.
