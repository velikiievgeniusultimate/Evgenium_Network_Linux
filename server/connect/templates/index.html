ШАГ 3 ИЗ 3

Откройте файл в WireGuard

  1. Откройте WireGuard. Нажмите «Добавить туннель» или «+», затем «Создать из файла или архива».
  2. Выберите скачанный файл EVG-….conf. Его можно найти через «Обзор» → «iCloud Drive» или «На iPhone» → «Загрузки».
  3. Когда iPhone предложит добавить VPN-конфигурацию, нажмите «Разрешить». Если попросит, подтвердите кодом разблокировки iPhone.
  4. Включите переключатель справа от нового подключения. Откройте нужный сайт и проверьте интернет.

Готово. В следующий раз просто включайте и выключайте VPN в WireGuard. Заново вводить токен и скачивать файл не нужно.

Само скачивание VPN не включает. После успешного импорта файл можно удалить из «Загрузок» — подключение останется в WireGuard.

Если что-то не получилось

Не могу найти скачанный файл

В Safari нажмите значок загрузок у адресной строки и откройте список загрузок. Или откройте приложение «Файлы» → «Обзор» → «iCloud Drive» → «Загрузки». Если там пусто, проверьте «На iPhone» → «Загрузки»: место сохранения зависит от настроек Safari.

Затем вернитесь в WireGuard и выберите этот файл через «Создать из файла или архива». Нужен именно файл с окончанием .conf, его не нужно открывать как текст или устанавливать через настройки iPhone.

Токен не принимается

Скопируйте всю строку, начиная с EVN1-, без кавычек. Если ошибка остаётся, попросите владельца сети проверить ваш доступ. Токен нельзя заменить паролем от телефона.

Переключатель включён, а интернета нет

Отключите другие VPN-приложения и попробуйте наш VPN сначала по Wi-Fi, затем через мобильную сеть. Если работает только в одной сети, возможно, другая блокирует WireGuard. Напишите владельцу сети, где именно не работает. Повторное скачивание файла такую блокировку не исправит.

Хочу подключить ещё одно устройство

Откройте этот сайт на новом устройстве и введите тот же токен. Для него будет создан отдельный файл. Один файл нельзя использовать одновременно на нескольких устройствах: соединение будет прерываться.

Файл подходит для официального WireGuard на iPhone, iPad, Mac, Windows, Android и Linux. В этом варианте нет автоматического выбора резервных туннелей, который есть в приложении Evgenium. Доступ к локальной сети зависит от маршрутов устройства.
