# Android alpha: проверка 22 октября 2026

Это результаты конкретных испытаний, а не гарантия совместимости со всеми телефонами.

## Сборка

- Java 21, Gradle 8.13, Android SDK 36, NDK 27.3.13750724.
- ARM64, ARMv7, x86_64; остальные ABI исключены из APK целиком.
- 92 unit-теста успешно: 83 upstream + 5 тестов кадров + 4 теста рейтинга.
- Тест кадров включает 20 000 детерминированных случайных входов и проверку
  длины, усечения, повторного номера, heartbeat и фрагментированного чтения.
- Проверены ELF LOAD alignment 16 КиБ у ARM64/x86_64, включая Conscrypt,
  и zipalign -P 16. Реального запуска на 16-КиБ устройстве пока не было.

## LTE MegaFon

При выключенном VPN TCP-соединение к Яндексу успешно (105 мс), соединения к API
нашего российского сервера, двум входам Эстонии и 1.1.1.1:443 получали быстрый
отказ. Все четыре VPN-маршрута в первой серии не подключились. Это ограничение
наблюдаемого мобильного пути; причина (оператор, профиль доступа и т. п.) не доказана.
Повторный прогон всех четырёх маршрутов на исправленной сборке также не подключился.
Нужен повтор на свободном мобильном интернете. Сравнения скорости LTE нет.
После опыта восстановлены Wi-Fi=включён, мобильные данные=выключены.

## Android 8 / API 26

Эмулятор x86_64: установка, Keystore, CSR, выдача сертификата и обычный маршрут
HSVDS → Эстония проверены. TLS 1.3 с Conscrypt и EvgeniumTunnel также установили
VPN и подтвердили выход Эстонии через лабораторную TCP-пересылку ADB → SSH →
HSVDS → Эстония. Проверка CA/имени сервера и взаимная аутентификация сохранены.
Это проверяет совместимость ядра/криптографии, но не качество прямого маршрута:
обычный прямой TCP из эмулятора и с хоста зависал в текущем вложенном VPN-пути.

## Принудительный обрыв

После исправления проверки выхода: 22.10.2026 01:56:24–01:58:24 МСК,
EvgeniumTunnel на телефоне принудительно недоступен 90 секунд. После двух
ошибок проверки выбран следующий маршрут TLS; успешный выход Эстонии в 01:56:49.
58 отдельных HTTPS-проб: 6 заблокированных во время обрыва, 52 с выходом Эстонии,
0 с неожиданным внешним IP. Это выборочные сетевые пробы, не доказательство
отсутствия утечек всех протоколов во всех авариях.

Повторный опыт 02:02:54–02:04:54 МСК после передачи всех повторов подключения
под управление Engine: 53 пробы, 8 заблокированных, 45 с выходом Эстонии,
0 с неожиданным IP. Переход на второе место нового рейтинга (HSVDS) подтверждён
в 02:03:27. После этого изменено только однократное потребление ADB-команд
интерфейсом и исправлена установка SDK в CI; сетевое ядро не менялось.

В предыдущих опытах обнаружены и исправлены: NetworkOnMainThreadException в
самой debug-команде обрыва и очередь HTTP-проверок, занятая зависшими DNS.
Проверка выхода теперь обращается к фиксированному IP с полноценной HTTPS
аутентификацией. Для Android 8–9 добавлен недостающий публичный корневой CA
только в локальный контекст этой проверки; проверка на эмуляторе прошла.

Переименование телефона в Evgenium-Phone через экран приложения подтверждено
на сервере в device_names тестового аккаунта. Имя сохраняется при обновлении APK.
