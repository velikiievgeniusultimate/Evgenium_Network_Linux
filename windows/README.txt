Evgenium Network для Windows 10/11 x64 — 0.2.1, исправленный интерфейс WPF и права обычного пользователя

УСТАНОВКА И ПЕРВЫЙ ЗАПУСК
1. Запустите Evgenium-Windows-0.2.1-x64-Setup.exe и подтвердите UAC.
2. Откройте Evgenium Network через меню «Пуск» или ярлык рабочего стола.
3. Вставьте токен EVN1, нажмите «Подтвердить», затем «Подключить».
4. Разрешите запуск VPN своей учётной записью Windows, когда появится UAC.
Все необходимые компоненты входят в установщик. Отдельная установка WireGuard,
командная строка и изменение политики выполнения PowerShell не нужны.

ОКНО И СИСТЕМНЫЙ ТРЕЙ
Верхняя полоса перетаскивает окно. Справа — «Свернуть» и «Закрыть».
Размер меняется за края и углы; кнопки разворота нет.
Закрытие окна скрывает его в системный трей и не отключает VPN.
Двойной щелчок по значку в трее открывает окно. Через меню трея можно полностью
закрыть интерфейс. Для остановки VPN используйте «Отключить».
Старое плавающее окно виджета удалено.
Флажок «Запускать с Windows» запускает интерфейс при входе пользователя.

ТОКЕН И ИМЯ
Один токен — для одного человека и всех его устройств. На каждом устройстве
создаётся свой закрытый ключ. После подтверждения токен скрыт; «Изменить»
показывает его и разрешает замену при отключённом VPN.
Имя устройства назначается сервером, затем его можно изменить в приложении.
Токен и ключ защищены DPAPI текущего пользователя Windows. Конфигурация службы
доступна только пользователю, SYSTEM и администраторам.
Не передавайте каталог %LOCALAPPDATA%\EvgeniumNetwork другим людям.

ПОДКЛЮЧЕНИЕ И ИСКЛЮЧЕНИЯ
Компьютер -> HSVDS -> межсерверный канал -> Эстония.
Интерфейс показывает подключение после проверки ожидаемого внешнего IP.
Служба VPN работает независимо от окна. При обрыве она восстанавливает связь;
защита блокирует обычный выход, кроме явно разрешённых исключений.
Для возврата к обычному интернету нажмите «Отключить».

Исключения направляют трафик напрямую:
- «Приложения»: выберите запущенное приложение, файл .exe или укажите путь.
- «Сайты и IP»: домен, IP или подсеть. =example.org означает точное имя;
  example.org включает также поддомены.
- «Порты»: протокол, порт и направление. Не указывайте адрес сайта вместо порта.
- «DNS»: отдельный разрешённый DNS-сервер. Он увидит направленные ему запросы.
Кнопка «Отобразить базовые исключения» открывает переключатели базовых правил.
Автоматический выбор маршрута использует сохранённый рейтинг и восстановление;
при необходимости маршрут можно выбрать вручную. «Восстановить» сбрасывает
предыдущие результаты и повторяет проверку.

ДИАГНОСТИКА
«Полная диагностика» запрашивает согласие, проверяет доступные маршруты,
DNS/HTTPS, скорость, доставку тестовых UDP-пакетов и сетевые счётчики, затем
отправляет технический отчёт на сервер. Содержимое пользовательского трафика,
история посещений, токен и ключи в отчёт не включаются.
При ошибке отправки отчёт сохраняется только на устройстве.

ОБНОВЛЕНИЯ
Новый Setup.exe обновляет существующую установку с сохранением токена,
ключей, имени и настроек. Удалять предыдущую версию перед обновлением не нужно.
Кнопка «Проверить обновления» получает установщик из того же репозитория GitHub,
проверяет версию, размер и SHA256 и запускает обычное обновление с UAC.
Не выключайте компьютер во время установки. Обновление может прервать
подключения на время перезапуска VPN. Повторный запуск той же версии
установщика восстанавливает файлы приложения.
Репозиторий:
https://github.com/velikiievgeniusultimate/Evgenium_Network_Linux

УДАЛЕНИЕ
Параметры Windows -> Приложения -> Evgenium Network -> Удалить.
Удаляются собственная служба, защита, настройки, ключи, ярлыки и файлы приложения.
Не удаляйте Program Files вручную при включённом VPN: сначала используйте
штатное удаление либо выключите VPN в приложении.
Удаление приложения не отзывает устройство в панели владельца.

ОГРАНИЧЕНИЯ
Пройден полный сетевой прогон на отдельной Windows Server 2022 машине.
Физический Windows 10/11 ПК отдельно проверит владелец; это первый выпуск нового клиента.
Для управления VPN нужна учётная запись администратора с подтверждением UAC.
Собственный EXE пока не имеет сертификата подписи издателя. Не отключайте
антивирус и SmartScreen. Проверяйте источник установщика и SHA256.
Драйвер Wintun подписан издателем WireGuard. Другие VPN приложение не выключает.
Windows ARM64, Windows 7/8 и Wine не поддерживаются.
