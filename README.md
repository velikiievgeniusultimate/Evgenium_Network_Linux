# Evgenium Network Linux

Версия **0.4.3**. Один VPN по клиентскому токену:
компьютер → российский HSVDS → Эстония.

## Установка и обновление

Поддерживаются Arch Linux и Fedora KDE на x86_64/aarch64. Установщик ставит
системные зависимости и проверенный локальный обработчик правил автоматически.
Проверки на реальном компьютере выполнены на Arch x86_64; это не подтверждение
работы каждой версии дистрибутивов и архитектур.

```bash
curl -fsSL https://raw.githubusercontent.com/velikiievgeniusultimate/Evgenium_Network_Linux/main/install.sh | bash
```

Для существующей установки:

```bash
vpn update
```

### Восстановление сломанной установки

Если после перехода с 0.2.x не запускается `vpn`, остался старый GUI или обновление
прервалось, закройте окно Evgenium Network и выполните от обычного пользователя:

```bash
curl -fsSL https://raw.githubusercontent.com/velikiievgeniusultimate/Evgenium_Network_Linux/main/install.sh | bash -s -- --repair
```

Это независимая переустановка файлов программы: старый CLI не запускается.
Установщик скачивает актуальный stable, проверяет SHA-256 и ставит зависимости,
CLI, GUI и уже установленный виджет. Токен, ключи устройства и исключения сохраняются.
Перед заменой создаётся закрытая резервная копия в `/var/lib/vpn-manager/backups/`.
Обычная команда установки и `--reinstall` выполняют такое же восстановление;
удалять пользовательские папки вручную не нужно.

На Arch отсутствующая база стороннего репозитория (например, `openai-chatgpt`)
не мешает восстановлению: установщик пропускает такой репозиторий только в своей
временной конфигурации pacman. Системные настройки, зеркала и проверка подписей
сохраняются. Если отсутствует официальная база Arch, установщик останавливается
с объяснением; частичное обновление баз автоматически не выполняется.

После успешного завершения откройте приложение заново и проверьте `vpn version`.
Если завершение установки прервалось, `vpn update` повторяет его даже при совпадении
номера версии. Если сам CLI повреждён, используйте команду `--repair` выше.
Пользователям старого VLESS без клиентского токена нужно получить токен у владельца сети.

Откройте Evgenium Network, вставьте токен клиента, нажмите «Подтвердить»,
затем «Подключить». Один токен принадлежит одному человеку и подходит для его
устройств; ключ устройства создаётся на самом устройстве.

## Исключения

Весь обычный трафик направляется через VPN. Включённые исключения используют
прямое подключение и внешний адрес вашего провайдера.

- **Приложения:** имя процесса или полный путь; можно выбрать запущенную программу.
- **Сайты и IP:** домен, точный домен с префиксом `=`, адрес или подсеть.
- **Порты:** протокол, номер и направление — исходящие, входящие ответы сервера, оба.
- **DNS:** адрес DNS-сервера, к которому разрешены обычные DNS-запросы напрямую.
  Это явное разрешение раскрывать этому серверу запрашиваемые имена.
- **Waydroid:** отдельный переключатель. По умолчанию весь его трафик, включая DNS,
  идёт напрямую. Его можно переключить в VPN независимо от остальных приложений.
  Сеть Waydroid отслеживается и при запуске после VPN или пересоздании контейнера.
  DHCP остаётся локальным; DNS контейнера направляется на 1.1.1.1 выбранным для Waydroid
  путём, поэтому в режиме обхода он также идёт напрямую.

Во вкладках исключений есть «Отобразить базовые исключения»; у каждого базового
правила отдельное включение. Скрытие списка не выключает правила. Базовые правила:
текущая локальная сеть, link-local устройства, локальное обнаружение устройств,
локальный системный DNS и Waydroid Mapper. Обычные сайты, браузер и Codex в базовые
прямые исключения не входят. Явные пользовательские списки прежней версии мигрируют.

Переключение правил применяется сразу; открытые соединения могут переподключиться.
Доменные правила используют распознавание HTTP/TLS/QUIC. Если приложение скрывает
имя назначения или использует другой протокол, примените исключение приложения
либо IP. Полное имя исполняемого файла надёжнее сокращённого имени процесса;
приложения с отдельными сетевыми помощниками могут требовать правила для помощника.

## Защита и совместимость

Локальные службы компьютера остаются доступными. DNS по умолчанию идёт через VPN,
даже когда доступ к роутеру и домашним устройствам разрешён. Исключения DNS и полный
обход Waydroid включают прямую передачу DNS только по явному правилу.

При потере туннеля обычный трафик блокируется. Разрешённые прямые исключения могут
продолжать работать. «Восстановить» повторяет подключение, «Отключить» возвращает
обычную сеть. Перезагрузка после аварии сохраняет защиту до восстановления либо
явного отключения. Автоматического подключения после включения компьютера пока нет.

Предыдущие VLESS-профили и режим удалены из приложения и рабочего кода клиента.
Xray используется только локально для распознавания приложений/доменов; он не
создаёт старое VLESS-подключение. Его VPN-выход направлен в новый IPsec-туннель,
а прямой выход доступен только выбранным правилам. Публичного DIRECT SOCKS нет.

Токен, ключи и сертификаты сохраняются при обновлении. Старые профильные файлы
перед удалением архивируются локально в закрытом `/var/lib/vpn-manager/legacy-before-0.4.0.tar.gz`.
Основные правила: `/etc/vpn-manager/policy.json`. Секреты не помещаются в репозиторий.

После подтверждения токена сервер назначает имя «Устройство-1», «Устройство-2» и так далее
в пределах пользователя. Имя меняется вверху окна или через CLI и отображается в веб-панели.
Если сервер временно недоступен, выбранное имя сохраняется локально и отправляется при
следующем подключении; интерфейс показывает, что синхронизация ещё не завершена.

`vpn on` и `vpn repair` показывают этапы и ждут подтверждения выхода в Эстонии.
Для фонового запуска есть `--no-wait`. Просто `vpn` выводит состояние и подсказку команд.
`vpn watch` показывает изменения, а Ctrl+C прекращает только вывод, сохраняя VPN.

## Команды

```bash
vpn on
vpn off
vpn repair
vpn toggle
vpn status --ip
vpn status --json
vpn watch
vpn rules
vpn base list
vpn base disable networks lan
vpn base enable networks lan
vpn waydroid direct
vpn waydroid vpn
vpn device name "Мой ноутбук"
vpn app add /usr/bin/firefox
vpn direct add example.com
vpn port add tcp:25565:in
vpn dns add 192.168.1.1
vpn app list
vpn direct remove example.com
vpn widget install
vpn logs -n 100
vpn update
```

## Проверки перед выпуском

`python3 -m unittest discover -s tests -v` проверяет токены/сертификаты, миграцию,
проверку входных данных, откат изменений правил, интерфейс, блокировку операций
и состав релиза. `sudo python3 scripts/test-unified-policy.py` создаёт изолированные
сетевые пространства с двумя разными маршрутами и настоящим Xray TUN: проверяет
направление приложений/домена/IP/порта/DNS, Waydroid, локальный DNS и остановку движка.
Маршруты и службы основного компьютера этот стенд не меняет.

`python3 scripts/test-upgrade-sandbox.py` (нужен bubblewrap и системные зависимости VPN/Qt)
проверяет переход из настоящего архива 0.2.7 и независимую переустановку при сломанном CLI.
Файловая система теста временная, сеть изолирована, systemd заменён заглушкой.


### Виджет VPN на рабочем столе

Компактный виджет как E-VPN в Plasma: только **E-VPN** и переключатель,
164 × 48 пикселей. Он постоянно расположен на рабочем столе, под окнами
приложений; не исчезает при потере фокуса. В XFCE/X11 закрепляется на всех
рабочих столах и остаётся видимым при «Показать рабочий стол».

```bash
vpn desktop install
evgenium-network --widget --detach
```

Перетаскивайте за имя. Положение сохраняется. Настройки и закрытие доступны
через правый клик, состояние и ошибки — во всплывающей подсказке.
Установка добавляет автозапуск. Старый вариант в трее удалён.
`vpn tray install|remove` оставлен как совместимый псевдоним.
В KDE доступен и родной Plasma-виджет: `vpn widget install`.
Для сеанса Wayland без XWayland используйте родной Plasma-виджет.

Обновление — **`vpn update`**. Файлы встроены в проверяемый релиз менеджера;
работающий виджет перезапускает интерфейс после замены файлов.
`vpn desktop remove` убирает автозапуск и пункт меню.

Переключение настоящего VPN проверяется пользователем вручную:
агент, работающий через VPN, может потерять связь при отключении.
